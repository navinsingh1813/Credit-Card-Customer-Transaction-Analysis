## Project Overview

This project analyzes customer demographics, transaction behavior, revenue generation, spending patterns, and card performance using SQL Server and Power BI.

The objective is to transform raw financial data into actionable insights that help identify high-value customer segments, spending behavior, and business growth opportunities.

---

## Business Problem

Financial institutions rely on customer and transaction data to understand customer behavior and improve profitability.

This project focuses on identifying:

* High-value customers
* Revenue-driving factors
* Spending patterns
* Card category performance
* Customer satisfaction trends

---

## Tools & Technologies

* SQL Server

* Power Query

## Key Insights

### Revenue by Card Category

Blue cards generated the highest revenue contribution.

### Top Revenue-Generating Customer Segment

Business professionals and white-collar workers contributed the largest share of revenue.

### Spending Categories

Bills, Entertainment, and Fuel represented the highest spending categories.

### Geographic Analysis

Texas, New York, and California contributed the highest revenue.

### Education Analysis

Graduate customers generated the highest overall revenue.

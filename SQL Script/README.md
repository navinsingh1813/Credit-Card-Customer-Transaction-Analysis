# SQL Scripts

## Overview

This folder contains SQL Server scripts used to prepare, clean, transform, and analyze the credit card customer and transaction data.

## Key SQL Concepts Used

* Database Creation
* Table Creation
* Data Import
* Joins
* Aggregate Functions
* Group By
* Date Functions
* Data Validation
* Business Analysis Queries

## Purpose

The SQL layer was used to prepare the data before connecting it to Power BI for visualization and reporting.

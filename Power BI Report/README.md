# Power BI Dashboard

## Dashboard Overview

This dashboard analyzes customer demographics, transaction behavior, revenue performance, spending categories, and card performance.

The dashboard is divided into two analytical views:

### Customer Report

Provides insights into:

* Revenue Trends
* Customer Segmentation
* Income Analysis
* Customer Satisfaction
* Education Analysis
* State-wise Performance

### Transaction Report

Provides insights into:

* Transaction Trends
* Spending Categories
* Card Category Performance
* Revenue by Job Type
* Revenue by Education Level
* Revenue by Payment Method

## Tools Used

* Power BI Desktop
* Power Query
* DAX
* Data Modeling
* Interactive Visualizations

# Dataset Information

## Dataset Overview

This project uses customer and credit card transaction datasets to analyze customer behavior, revenue generation, spending patterns, and card performance.

The datasets were imported into SQL Server and later connected to Power BI for dashboard development and business analysis.

## Files Included

* customer.csv
* credit_card.csv
* cust_add.csv
* cc_add.csv

## Analysis Areas

* Customer Segmentation
* Revenue Analysis
* Transaction Analysis
* Spending Behavior
* Geographic Performance
* Card Category Analysis

## Purpose

The dataset was used to identify high-value customers, spending trends, and revenue-driving factors to support business decision-making in the financial services domain.

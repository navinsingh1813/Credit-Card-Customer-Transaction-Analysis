# Business Problem

Financial institutions generate large volumes of customer and transaction data through credit card usage.

The objective of this project is to analyze customer demographics, spending behavior, transaction patterns, revenue generation, and card performance to identify business opportunities, improve customer engagement, and support data-driven decision-making.

Key focus areas include:

* Customer Segmentation
* Revenue Analysis
* Interest Income Analysis
* Spending Categories
* Card Category Performance
* Customer Satisfaction
* Geographic Analysis
